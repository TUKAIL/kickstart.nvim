 报错原因可以总结成两层：

 1. 根因：WSL2 上 io_uring 特性兼容性不足
     - vortex-bittorrent 在启动时会这样创建 ring：
         - setup_single_issuer()
         - setup_clamp()
         - setup_cqsize(...)
         - setup_defer_taskrun()
         - setup_coop_taskrun()
     - 在你的环境里：
         - 内核：5.15.167.4-microsoft-standard-WSL2
     - 这里 .build(...) 返回了：
         - Os { code: 22, kind: InvalidInput, message: "Invalid argument" }
     - 这通常表示：当前 WSL2 内核/实现不接受其中某些 io_uring setup flags 组合，不是 magnet 命令写错。

 2. 次要问题：项目对错误处理不够稳
     - torrent.rs:157 对 .build(...) 直接 unwrap()，导致一旦 io_uring 初始化失败就立刻崩溃。
     - 你前面看到的：
         - Command channel to not be full: SendError { .. }
     - 更像是主线程/子线程在异常退出后的连带 panic，不一定是最初根因。
     - 真正的首个关键错误是 io_uring 初始化失败。
